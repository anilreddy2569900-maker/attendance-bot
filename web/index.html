Excel format — what the sheet should look like
AB
1NameUG Number
2Rohan Mehta41923
3Simran Kaur43517
  • One student per row: name in one column, UG number in another. Column order doesn't matter — the number column is found automatically.
  • UG number = just the number, like 41923. Do not type UG/26/41923 — the site adds UG/26/ itself. (Full IDs still work if you already have them.)
  • Header row is optional — a row saying “Name / UG Number” is skipped automatically.
  • Empty rows, duplicates and typos (like 4I923 with a letter I) are skipped and listed as warnings.
  • Also works with .csv, .txt, or a list pasted as Name number per line.
