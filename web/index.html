How to add your students (read this once)

Pick any one of these three ways. The page works out the rest.

Way 1 — Excel (.xlsx) or CSV

  1. Open Excel. In the first row type Name and UG Number (optional, but good).
  2. Type one student per row: name in one column, the number in the next.
  3. Save it, then drop the file on this page. A CSV is just a simple version of the same table: in Excel choose Save As → CSV.

Way 2 — Text file (.txt)

Open Notepad. Type one student per line, like Rohan Mehta 41923. Save as a .txt file and drop it here.

Way 3 — Paste

Open “Or paste the list instead” below, paste your lines, press Add pasted list. No file needed.

What works and what doesn't

  • UG number = only the number, like 41923. The site adds UG/26/ for you.
  • Name first or number first — both work. Just keep each student on one row/line.
  • Excel reads the first sheet only.
  • Mistakes are skipped, not guessed: typos, blank rows and duplicates show up as yellow warnings under the list.
  • Always check the list that appears after you add students. If a name is missing, fix it and add again.
  • Adding again adds to the list (it doesn't replace it). Use × to remove one student or Clear list to start over.
  • Your list is saved on this device and browser only. On another phone or computer, add it again.
